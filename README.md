# Mental Health Analyzer

## Project Description

Mental Health Analyzer is a machine learning-based web application designed to assess mental health risk using questionnaire responses and provide personalized recommendations.

## Features

- Student Mental Health Assessment
- Machine Learning Risk Prediction
- Personalized Recommendations
- Interactive Dashboard
- Analytics and Reports

## Technologies Used

- React
- Node.js
- Express.js
- SQLite
- Python
- Scikit-learn
